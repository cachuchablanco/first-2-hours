# Facilitator guide (90 minutes)

For small-org staff, not a SOC. Also works in an interview: walk the checklist out loud.

**Stuff:** printed [checklist](../checklists/first-2-hours.md), [roles](roles.md), [injects](injects.md), a timer, a whiteboard for the log.

## Setup (5 min)

- Assign seats.
- Ground rules: no malware, no real PHI, no "hack them back."
- Write the backup sentence on the board first, or use the lab one: "Nightly NAS. Weekly USB someone takes home. Restore last tested: unknown."

## Run of show

| Clock | Block |
|-------|--------|
| 0:00–0:05 | Setup |
| 0:05–0:20 | Inject 1 — discovery. Let them fumble comms. |
| 0:20–0:40 | Inject 2 — more PCs. Force a contain decision. |
| 0:40–0:55 | Inject 3 — a patient at the desk. |
| 0:55–1:10 | Inject 4 — backup truth and a bad idea (USB, decryptor, pay). |
| 1:10–1:20 | Inject 5 — reporter / "are we notifying?" |
| 1:20–1:35 | Decisions for the next 24 hours |
| 1:35–1:50 | Hotwash: what was missing before today |

## What I am scoring (not "did they name the malware")

1. Did someone take IC, or did three people give orders?
2. Isolate without wiping?
3. Did clinical get a vote on stay-open?
4. Backups as a question, not an assumption?
5. Comms on a clean channel?
6. Decisions written down?

## Interview version (15 min)

Skip the role-play. Walk the checklist with the sample AAR. That is the demo.
